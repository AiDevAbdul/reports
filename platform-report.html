Feature Modules

Platform Features

Organized by product area — every module has backend APIs, custom React hooks, and a dedicated dashboard page.

Analytics Core

📊

Multi-channel KPI Overview

Aggregated metric cards across all active sources. Configurable KPI list per client — enable/disable metrics, edit labels, set targets.

📈

Trend Charts with Forecasting

Area charts with dashed forecast lines. Linear regression on 90-day history projects N days ahead with 95% CI bounds and a reference date line.

🎯

Attribution Modeling

Four models: linear, last-click, first-click, time-decay. Side-by-side comparison table and % credit progress bars per channel.

⚡

Budget Pacing

MTD spend vs daily target band chart. PacingBadge (On Pace / Overpacing / Underpacing) on paid channel pages. Email alert when projected overrun >10%.

🔍

Anomaly Detection

Z-score based detection on daily metric trends. Alerts surfaced on the Notifications page and pushed via email or Slack webhook per client preferences.

🗂

Drag-Drop Widget Layout

@dnd-kit powered overview customization. Widget visibility + order persisted per user+client in user_dashboard_layouts. "Customize" toggle reveals drag handles.

Agency & Client Management

🏢

White-Label Branding

Per-client company name, logo URL, brand color (injected as --brand-primary CSS var), custom domain. Sidebar, top nav, and footer all adapt dynamically.

👥

Team Access Management

Role-based access (super_admin, client admin, viewer). Agency super-admin can impersonate any client for support and QA.

🌐

Client Portal

Public-facing /portal/[clientSlug] — server-rendered 30-day KPI summary with branded header. Respects agency-configured section toggles (KPIs, Trend, Channels, Spend).

🔗

Shareable Report Links

One-click data snapshots generate a public /r/[token] URL with optional expiry. View count auto-increments. No login required for recipients.

🎯

Goal Tracking

Per-client monthly/quarterly/annual targets per metric. Progress bars on Settings > Goals and on the Overview widget. PATCH/DELETE per goal.

⚙️

Automation Rules Engine

Trigger email or Slack actions when a metric crosses a threshold or drops by a %. Evaluated every nightly cron run. Full CRUD in Settings > Automation Rules.

Reporting & Notifications

📧

Scheduled Reports

Daily/weekly/monthly email reports via Resend. Configurable from Reports page. Full history stored in report_history and visible in the UI.

📋

Notification History

All anomaly alerts and automation-triggered actions persisted to notification_history. Displayed in the Notifications page with an "Alert History" tab.

📤

Export Connectors

Google Sheets: /api/export/sheets returns JSON or CSV for IMPORTDATA. Looker Studio: community connector endpoint with 30+ field definitions.

Caching Strategy

Two-layer cache: Upstash Redis (server-side, 10 min TTL) for query results, and TanStack Query (client-side, 5 min staleTime). Keys namespaced by metrics:{type}:{clientId}:... for per-tenant isolation.

Redis 10 min TanStack 5 min Per-tenant keys

Tenant Isolation

Every API route reads client_id from the signed JWT (da_token) and applies it as a hard WHERE clause. Agency impersonation uses a separate da_agency_token cookie with explicit client override.

JWT-signed tenant Hard WHERE clause
